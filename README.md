# DwellerMC Admin Wiki

Private admin documentation for the DwellerMC plugins (install, config reference, troubleshooting). Players use the public DwellerMC-wiki instead.

## Reading it
- **On GitHub:** open the `docs/` folder. Every page is Markdown and renders there.
- **As a site, locally:**
  1. `pip install -r requirements.txt`
  2. `mkdocs serve` (on this PC: `C:/Users/craft/AppData/Local/Python/pythoncore-3.14-64/python.exe -m mkdocs serve`)
  3. Open http://127.0.0.1:8000

Every fact here comes from the plugin code and default configs. When a plugin changes, the matching page is updated in the same session.
